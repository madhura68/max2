### Model

Hier is de definitieve prompt. Ik heb de aanname gemaakt dat je de Ollama API lokaal op de standaard poort (11434) draaiend hebt, aangezien je "lokale Mac" had geadviseerd.

```markdown
<context>
Ik heb Ollama draaiend op mijn lokale Mac. Ik wil een lichtgewicht dashboard om de prestaties van mijn modellen in realtime te monitoreren.
</context>

<task>
Bouw een enkel HTML-bestand met daarin een dashboard dat de status van Ollama modellen toont. Het dashboard moet direct in de browser werken zonder build-stappen of server-side code.
</task>

<constraints>
- Focus alleen op twee metrics: Tokens per seconde (tok/s) en VRAM-gebruik.
- Geen login-scherm, geen autorisatie.
- De interface moet minimalistisch en schoon zijn.
- Geen externe CSS of JS frameworks die via CDN geladen moeten worden; gebruik alleen vanilla JavaScript en CSS, of inline libraries indien essentieel (maar liever geen).
- Haal de data via de lokale Ollama API (standaard poort 11434).
</constraints>

<done_when>
- Het dashboard laadt in de browser.
- Het toont live tokens per seconde en VRAM verbruik.
- De gegevens updaten automatisch in realtime (bijv. elke 2 seconden).
</done_when>

<output_format>
Een enkel, compleet HTML-bestand met de nodige CSS en JavaScript inline. Voeg korte instructies toe over hoe het te gebruiken (bijv. "sla op als index.html en open in browser").
</output_format>
```

Aannames:
- Ollama draait lokaal op poort 11434.
- De API endpoints voor metrics zijn toegankelijk via de standaard Ollama API (of een specifieke endpoint als die er is, zoals `/api/stats`).
- VRAM-metrics zijn beschikbaar via de API of worden geschat op basis van model-load.

Instellingen: effort medium.
