# Transcript 4cb555 (R03: vaag bouwidee)

### Gebruiker

Ik wil een dashboard voor mijn Ollama-modellen op max2.

### Model

Dit is een bouwtak, dus ik wil eerst een paar dingen weten om de prompt goed af te bakenen:

1. Wat moet het dashboard tonen? [standaard: lijst van geïnstalleerde modellen, hun grootte en of ze geladen in het VRAM zijn]
2. Mag Ollama's API (lokaal op de machine met de GPU) als data-bron gebruikt worden? [standaard: ja, via `http://localhost:11434/api`]
3. Hoe wil je het dashboard gebruiken: een simpele lokale webpagina die je zelf opent, of een statisch HTML-bestand dat je periodiek laat genereren? [standaard: een lokale webpagina die live bijwerkt]
4. Moet het ook acties kunnen uitvoeren (model laden, verwijderen, runnen), of alleen status tonen? [standaard: alleen status tonen]

### Gebruiker

Akkoord. Extra: alleen tokens per seconde en VRAM, geen login.

### Model

```
<context>
Ik wil een dashboard voor mijn Ollama-modellen op een machine met een GPU (max2). Het dashboard is puur informatief en wordt lokaal gebruikt.
</context>

<task>
Bouw een lokale webpagina die live bijwerkt en alleen de volgende metaten toont:
- Tokens per seconde (throughput) per actieve Ollama-sessie of model.
- VRAM-gebruik per model.
</task>

<constraints>
- Gebruik de lokale Ollama API op `http://localhost:11434/api` als data-bron.
- Geen login of auth.
- Geen acties zoals model laden, verwijderen of runnen.
- Geen extra metaten: alleen tokens per seconde en VRAM.
- De pagina moet automatisch verversen zonder handeleiding.
</constraints>

<done_when>
- De webpagina laadt lokaal en toont live de tokens per seconde en VRAM-gebruik per model.
- Als geen modellen actief zijn, toont de pagina een lege of neutrale status.
- Er is geen login-scherm of auth-flow.
</done_when>

<output_format>
- Een volledige, werkende lokale webpagina (HTML + JS, eventueel een kleine server-side component als nodig voor CORS of polling).
- Korte uitleg hoe je het lokaal opstart.
- Geen extra features buiten tokens per seconde en VRAM.
</output_format>
```

Aannames:
- Ollama draait lokaal op dezelfde machine als de browser.
- "max2" betekent een GPU-machine waar Ollama al draait; de dashboard zelf heeft geen eigen GPU-requirement.
- Tokens per seconde wordt afgeleid uit de Ollama API of een lokale meting; als de API dit niet direct geeft, wordt het berekend uit response-tijden.
- "Live bijwerken" betekent polling met een redelijke interval (bijv. 1-2 seconden).
- Geen backend-database of persistentie; alleen live weergave.

Instellingen: effort medium.
Wil je nog iets aanpassen?
