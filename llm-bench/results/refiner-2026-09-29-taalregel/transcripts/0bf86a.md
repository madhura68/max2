# Transcript 0bf86a (R03: vaag bouwidee)

### Gebruiker

Ik wil een dashboard voor mijn Ollama-modellen op max2.

### Model

Ik wil je helpen om een duidelijke prompt te schrijven voor het bouwen van dit dashboard. Om het juiste formaat en de juiste technologieën te kiezen, heb ik nog een paar details nodig:

1. Hoe wil je dit dashboard draaien en gebruiken? [Standaard: een lokaal web-applicatie die je in je browser opent, met Python als backend]
2. Welke functionaliteiten zijn het belangrijkst? [Standaard: een overzicht van geïnstalleerde modellen, de mogelijkheid om modellen te starten/stoppen, en een simpele chat-interface om ze te testen]
3. Heb je voorkeur voor een specifieke tech-stack? [Standaard: Streamlit voor de snelste implementatie, of een moderne stack zoals React/Next.js als je een meer "professionele" UI wilt]
4. Moet het dashboard ook kunnen beheren welke modellen er zijn geïnstalleerd (bijv. nieuwe modellen pushen/pullen via de CLI)? [Standaard: alleen het monitoren en starten/stoppen van lopende modellen]

### Gebruiker

Akkoord. Extra: alleen tokens per seconde en VRAM, geen login.

### Model

Voordat ik de definitieve prompt schrijf, nog twee korte verduidelijkingen:

1. Wil je dat het dashboard **automatisch** de status van je Ollama-instantie ophaalt (bijv. via de Ollama API op `http://localhost:11434`), of moet je eerst specifieke commando's uitvoeren? [Standaard: het script koppelt zich aan de lokale Ollama API en haalt daar live data op]
2. Voor de "chat-interface": wil je dat je direct vanuit het dashboard kunt chatten met de modellen, of is het puur een monitoring dashboard? [Standaard: alleen monitoring (tokens/sec en VRAM), geen chatfunctie]

*(Mijn aanname is dat je doelt op een monitoring-dashboard, gezien de "geen login" en "alleen tokens/VRAM" opmerking. Als je toch een chat-interface wilt, laat het me weten.)*

### Gebruiker

Akkoord met je voorstellen.

### Model

```code
<task>
Bouw een lokaal webdashboard dat realtime de status van een draaiende Ollama-instantie monitort. Het dashboard moet een overzicht tonen van alle geïnstalleerde modellen, met live gegevens voor tokens per seconde (tokens/sec) en VRAM-gebruik per model.
</task>

<constraints>
- Het dashboard koppelt zich via de Ollama API (standaard `http://localhost:11434`) en haalt daar live data op.
- Er is geen login-scherm of authenticatie nodig.
- De focus ligt puur op monitoring: geen chatfunctie, geen model management (push/pull).
- Gebruik een eenvoudige, snelle stack zoals Python met Streamlit voor de frontend en backend.
</constraints>

<done_when>
Het dashboard start lokaal, toont een tabel met geïnstalleerde modellen, en update live de kolommen voor tokens/sec en VRAM-gebruik voor elk lopend model.
</done_when>

<output_format>
De volledige code voor het dashboard, de installatiestappen voor benodigde libraries, en instructies om het lokaal te starten.
</output_format>
```

Aannames:
- Doel is een monitoring-dashboard (geen chat).
- Gebruik van Streamlit voor snelle implementatie.
- Lokale Ollama API op `localhost:11434`.
- Geen authenticatie nodig.
- Focus op tokens/sec en VRAM als kernmetrics.

Instellingen: effort medium.

Wil je nog iets aanpassen?
