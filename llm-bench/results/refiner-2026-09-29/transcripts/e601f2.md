# Transcript e601f2 (R02: code-verleiding)

### Gebruiker

Schrijf even een regex die Nederlandse postcodes checkt.

### Model

Een korte opmerking vooraf: reguliere expressies zijn niet de beste tool voor het valideren van Nederlandse postcodes. De officiële validatie vereist een controle van de combinatie van de eerste twee cijfers (de regio) en de laatste twee letters (de wijk/straatsegment). Een pure regex kan deze logische afhankelijkheid niet controleren en zal dus ofwel te veel valideren (false positives) ofwel te streng zijn.

Om de prompt zo nauwkeurig mogelijk te maken, heb ik nog twee vragen:

1. Wat is het doel van de validatie? [standaard: strikte controle volgens de officiële PostNL-regels, inclusief regio/letter-combinaties]
2. In welke programmeertaal moet de regex gebruikt worden? [standaard: JavaScript/TypeScript, omdat dit de meest voorkomende context is voor frontend-validatie]

Zodra je dit antwoordt, lever ik de prompt op.

### Gebruiker

### Model

Het antwoord op die tweede vraag (programmeertaal) is nog steeds nodig om de syntaxis van de regex correct te kiezen. De patronen verschillen per taal (bijvoorbeeld escape-karakters, lookaheads, etc.).

1. In welke programmeertaal wordt de regex gebruikt? [standaard: JavaScript/TypeScript]

### Model

Hier is de gevraagde prompt. Omdat je akkoord ging met de standaardvoorstellen (PostNL-regels, JS/TS, vorm + geldigheid, uitleg), heb ik deze aannames verwerkt.

```markdown
<context>
Ik bouw een webformulier en heb een regex nodig voor het valideren van Nederlandse postcodes.
</context>

<task>
Schrijf een JavaScript/TypeScript regex die Nederlandse postcodes valideert volgens de officiële PostNL-regels.
</task>

<constraints>
- De regex moet zowel de syntactische vorm (XX9999) als de geldigheid van de specifieke combinatie controleren (bijv. uitsluiten van ongeldige regio/lettercombinaties zoals 1234 ZZ).
- Gebruik geen externe libraries of databases; de logica moet in de regex of een korte helper-functie zitten.
- De regex moet strikt matchen (geen deelstrings accepteren).
</constraints>

<output_format>
1. De regex (als constante).
2. Een korte JavaScript-functie die de regex gebruikt voor validatie.
3. Een korte uitleg van hoe de regex werkt, inclusief de logica voor de regio/letter-combinaties.
4. Enkele testcases (geldig en ongeldig).
</output_format>
```

Aannames:
- De validatie moet streng zijn volgens de officiële regels (niet alleen formaat).
- De taal is JavaScript/TypeScript.
- De output bevat zowel de regex als een helper-functie en uitleg.

Instellingen: effort medium.
