# Transcript 06c746 (R10: Engels)

### Gebruiker

I need a prompt to get Claude to help me write a cover letter for a data engineer job.

### Model

Laat me je helpen een effectieve prompt te maken. Om de prompt echt op maat te maken, heb ik wat specifieke informatie nodig.

1. Wat is de kern van je ervaring? [standaard: noem 3-4 relevante technische skills en jaren ervaring]
2. Voor welke specifieke rol of bedrijf schrijf je? [standaard: algemene data engineer rol, geen specifieke bedrijf]
3. Wat is de belangrijkste connectie tussen jouw profiel en de rol? [standaard: laat dit open voor Claude om te bepalen op basis van de aangeleverde details]
4. Welke toon en lengte heb je voor ogen? [standaard: professioneel maar toegankelijk, 300-400 woorden]

Antwoord met "ok" voor de standaardoptie, of geef je eigen invulling.

### Gebruiker

Go with your suggestions. Extra: the job is at a mid-size logistics company; I have 4 years of Python and Airflow experience.

### Model

Aangezien de extra informatie (logistieke sector, 4 jaar ervaring) de vorige vragen deels al invult, kan ik direct de prompt opstellen. Ik ga er vanuit dat je je CV of een lijst met projecten kunt aanleveren om de prompt concreet te maken.

Hier is de prompt, klaar om te kopiëren.

```prompt
<context>
Ik solliciteer op een Data Engineer rol bij een middelgroot logistiek bedrijf. Ik heb 4 jaar ervaring met Python en Airflow. De logistieke sector is vaak gericht op efficiëntie, real-time data en processoptimalisatie.
</context>

<material>
Hieronder volgt een opsomming van mijn belangrijkste vaardigheden en projecten (of plak hier je CV/informatie):
- Python (4 jaar): [bijv. data scraping, API integraties, data cleaning]
- Apache Airflow (4 jaar): [bijv. orchestration van ETL pipelines, monitoring]
- [Voeg hier nog 1-2 andere relevante tools toe, bijv. SQL, AWS/GCP, dbt]
- [Noem een specifiek resultaat of project dat relevant is voor logistiek/data pipelines]
</material>

<task>
Schrijf een overtuigende sollicitatiebrief (cover letter) voor deze Data Engineer rol.
</task>

<constraints>
- De toon is professioneel, zelfverzekerd en toegankelijk.
- Leg de link tussen mijn technische ervaring (Python/Airflow) en de behoeften van een logistiek bedrijf (bijv. betrouwbaarheid, schaalbaarheid, data-gedreven besluitvorming).
- Vermijd clichés en overbodige inleidingen.
- Focus op waardecreatie: hoe kan ik het team helpen?
</constraints>

<done_when>
De brief is tussen de 300 en 400 woorden, leest vloeiend en bevat geen vage generalisaties. Elke technische claim wordt gekoppeld aan een concreet voorbeeld of resultaat.
</done_when>

<output_format>
De volledige tekst van de brief in het Nederlands (of Engels, laat dit weten als je het in het Engels wilt). Geen markdown voor de tekst zelf, alleen de inhoud.
</output_format>

<check_in>
Als er cruciale informatie ontbreekt om een sterke link te leggen, vraag dan om specifieke details over mijn projecten voordat je de brief schrijft.
</check_in>
```

Aannames:
- Je wilt de brief in het Nederlands (verander `<output_format>` naar Engels indien nodig).
- De "material" sectie is leeg gelaten met instructies; vul deze met je echte data voor het beste resultaat.
- De focus ligt op de bruikbaarheid van Python/Airflow in een logistieke context.

Instellingen: effort medium.
