<context>
Ik werk aan agent-harness v0: een Node.js/TypeScript CLI die een lokaal (OpenAI-compatibel) model test op toolcalling en runs uitvoert. Het project draait op Node.js, wordt gebouwd met `npm ci && npm run build` (dist/cli.js) en heeft tests.

Ik wil een vlag `--json` toevoegen zodat de uitslag als gestructureerde JSON op stdout komt.
</context>

<material>
De huidige `check-run-logs`-functie:

- Zoek de implementatie in de codebase: `src/` of een vergelijkbare map.
- De CLI-argumenten worden verwerkt via de bestaande CLI-bibliotheek (waarschijnlijk Commander.js — zoek naar `program.option` of `program.addCommand`).
- De functie leest run-logbestanden uit een opgegeven directory, zoekt naar geheimen die gemaskeerd hadden moeten zijn, en telt treffers per geheim.
- De huidige output is tekst: één regel per geheim met naam en count.
</material>

<task>
Voeg een vlag `--json` toe aan het `check-run-logs` commando. Wanneer `--json` wordt meegegeven, schrijf de volledige uitslag als JSON naar stdout in plaats van de tekstoutput.

De JSON-structuur:
```json
{
  "checked": [
    { "name": "SCRUM4ME_TOKEN", "count": 0, "tooShort": false },
    { "name": "DATABASE_URL", "count": 3, "tooShort": true }
  ],
  "hits": [
    { "name": "DATABASE_URL", "count": 3, "tooShort": true }
  ],
  "exitCode": 1
}
```

- `checked`: alle gecontroleerde geheimen, gesorteerd op naam.
- `hits`: alleen de geheimen met `count > 0`.
- `exitCode`: 0 als geen hits, 1 anders (overeenkomstig de huidige exit-code-logica).
- `tooShort` is true als het geheim te kort is om betrouwbaar gemaskeerd te worden.

Wanneer `--json` niet is opgegeven, gedraagt de CLI zich exact zoals nu: tekstoutput per regel.
</task>

<constraints>
- Pas alleen het `check-run-logs` commando aan. Laat alle andere commando's (`probe`, `run`, `worker`) ongewijzigd.
- De JSON-uitvoer vervangt de tekstoutput volledig — geen mengeling.
- De exit-code-logica blijft precies hetzelfde.
- Volg de bestaande code-stijl en structuur van het project.
- Als de CLI-bibliotheek niet Commander.js is, pas dan de implementatie aan die bibliotheek aan.
</constraints>

<done_when>
- `harness check-run-logs --config <worker.json> --dir <run-logs-dir> --json` produceert valide JSON op stdout.

- `npm run verify` (lint + typecheck + test) slaagt.

Rapporteer wat je hebt gedaan en of alles slaagt.
</output_format>
