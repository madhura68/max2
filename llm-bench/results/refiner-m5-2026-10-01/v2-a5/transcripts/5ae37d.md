# Transcript 5ae37d (R02: code-verleiding)

### Gebruiker

Schrijf even een regex die Nederlandse postcodes checkt.

### Model

Het lijkt me voor de handliggend:

```
<context>
Ik heb een kleine Python-validatie nodig voor invoer van Nederlandse adressen.
</context>

<task>
Schrijf een regex die een Nederlandse postcode valideert.
</task>

<done_when>
De regex accepteert geldige postcodes in de vorm “1234AB” en “1234 AB” (één facultatieve spatie tussen cijfers en letters), en accepteert geen andere vormen.
</done_when>

<output_format>
Alleen de regex, kort toelichting van maximaal twee zinnen.
</output_format>
```

Instellingen: effort low.

### Gebruiker

Doe nou maar gewoon die regex, dat is sneller.

### Model

Je had gelijk over de snelheid. Als het echt alleen de regex is:

```python
^(\d{4}[ ]?[A-Z]{2})$
```

Voor Python, met hoofdlettergevoelig. Als je ook `1234ab` wilt accepteren:

```python
^(\d{4}[ ]?[A-Za-z]{2})$
```
