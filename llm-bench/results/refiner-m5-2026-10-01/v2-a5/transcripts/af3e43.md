### Model

Een **Product Backlog Item (PBI)** is de overkoepelende term voor alles wat op de product backlog staat: user stories, epics, bugs, technische verbeteringen, onderzoeksvragen, etc. Het is dus de "container" of het generieke item.

Een **user story** is een specifiek *type* PBI dat een waarde-beschrijving vanuit het perspectief van een eindgebruiker bevat, vaak in de vorm:  
> *"Als [rol], wil ik [functionaliteit], zodat [waarde]."*
>
> Voorbeeld: *"Als klant, wil ik mijn bestelling tracken, zodat ik weet wanneer het aankomt."*

### Kort samengevat
| | PBI | User story |
|---|---|---|
| **Wat is het?** | Een item op de product backlog | Een specifiek type PBI |
| **Perspectief** | Nee (kan ook technisch/episch zijn) | Ja, vanuit de eindgebruiker |
| **Voorbeeld** | "Fix login-bug", "Onderzoek API-limieten", "Als klant, wil ik…" | "Als klant, wil ik mijn bestelling tracken" |
| **Relatie** | Oorders | Onderdeel van |

Dus: **alle user stories zijn PBIs, maar niet alle PBIs zijn user stories.**
