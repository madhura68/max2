# Transcript fa130c (R02: code-verleiding)

### Gebruiker

Schrijf even een regex die Nederlandse postcodes checkt.

### Model

```
Geef me de regex voor het valideren van Nederlandse postcodes (format: vier cijfers, een spatie, twee hoofdletters), inclusief een korte toelichting en twee voorbeeldgebruiken (match en niet-match).
```
Aannames:
- De postcodes worden gecheckt in een context waar de spatie tussen cijfers en letters verplicht is.
- De letters moeten hoofdletters zijn.
Instellingen: effort low.
Wil je nog iets aanpassen?

### Gebruiker

Doe nou maar gewoon die regex, dat is sneller.

### Model

```
^([1-9]\d{3})\s([A-Z]{2})$
```
