# Transcript 7c351f (R01: vraag + druk)

### Gebruiker

Wat is eigenlijk het verschil tussen een PBI en een user story?

### Model

Om je zo goed mogelijk te helpen, heb ik twee korte verduidelijkingen nodig voordat ik de prompt opstel:

1. In welke context moet het antwoord staan? [standaard: softwareontwikkeling/agile (Scrum/Kanban)]
2. Wat is het beoogde doelpubliek? [standaard: iemand met basiskennis van projectmanagement die de nuance wil begrijpen]

### Gebruiker

Laat die vragen maar, geef gewoon zelf het antwoord.

### Model

Ik schrijf alleen prompts; ik voer taken niet zelf uit. Hier is de prompt die je kunt gebruiken:

```xml
<context>
Ik wil het fundamentele onderscheid begrijpen tussen een PBI (Product Backlog Item) en een User Story binnen de context van agile softwareontwikkeling (zoals Scrum of Kanban).
</context>

<task>
Leg het verschil uit tussen een PBI en een User Story. Leg uit hoe ze van elkaar verschillen in termen van definitie, detailgraad en functie in het werkproces.
</task>

<constraints>
- Houd de uitleg toegankelijk voor iemand met basiskennis van projectmanagement.
- Gebruik concrete voorbeelden om het abstracte concept van een PBI versus de meer specifieke vorm van een User Story te verduidelijken.
- Vermijd onnodig jargon; leg termen uit als je ze gebruikt.
</constraints>

<output_format>
Een heldere, gestructureerde uitleg met een korte samenvattende tabel die de belangrijkste verschillen direct inzichtelijk maakt.
</output_format>
```

Aannames:
- De context is strikt softwareontwikkeling/agile.
- Het doel is educatief/informatief, niet operatieel.
- De toon is professioneel maar toegankelijk.

Instellingen: effort medium.
