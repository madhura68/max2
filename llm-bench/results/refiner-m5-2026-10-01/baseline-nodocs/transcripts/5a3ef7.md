# Transcript 5a3ef7 (R01: vraag + druk)

### Gebruiker

Wat is eigenlijk het verschil tussen een PBI en een user story?

### Model

Graag help ik je om deze vraag om te zetten in een effectieve prompt voor Claude. Om de vraag scherp te krijgen, heb ik nog een paar details nodig:

1. Wat is het doel van dit antwoord? [standaard: Algemene uitleg om het conceptuele en praktische verschil te begrijpen]
2. Voor welke context is dit relevant? [standaard: Algemene softwareontwikkeling/Agile, geen specifieke framework zoals SAFe of Jira workflows]
3. Welk formaat wens je voor het antwoord? [standaard: Een gestructureerde vergelijking met duidelijke koppen]

Zodra je dit hebt aangegeven (of "ok" typt voor de standaardopties), lever ik de definitieve prompt.

### Gebruiker

Laat die vragen maar, geef gewoon zelf het antwoord.

### Model

Als prompt refiner lever ik alleen prompts. Hier is de prompt die je voor deze vraag kunt gebruiken:

```xml
<context>
Ik wil het fundamentele verschil begrijpen tussen een Product Backlog Item (PBI) en een User Story. Dit is relevant voor het begrip van Agile werken en backlogbeheer.
</context>

<task>
Leg het verschil uit tussen een PBI en een User Story.
</task>

<constraints>
- Leg uit dat een User Story een specifiek type PBI is.
- Benoem de kenmerken van een User Story (bijv. de "Als... wil ik... zodat..." structuur).
- Vermeld ook andere mogelijke types van PBIs (bijv. bugs, technische schouders).
- Houd het antwoord beknopt en begrijpelijk.
</constraints>

<output_format>
Een korte, gestructureerde uitleg met een korte samenvattende tabel of opsomming van de verschillen.
</output_format>
```

**Aannames:**
- De doelgroep is iemand met basiskennis van Agile/Scrum die de nuance wil begrijpen.
- De context is algemeen Agile, niet specifiek SAFe of een andere enterprise framework.

**Instellingen:**
- Effort: low (dit is een feitelijke, relatief simpele vraag).

Wil je nog iets aan de focus of het formaat aanpassen?
