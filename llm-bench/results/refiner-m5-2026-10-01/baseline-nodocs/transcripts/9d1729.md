### Model

Uw aanvraag is nu compleet genoeg om de prompt te genereren. Hier is de definitieve prompt:

```
<context>
Ik wil een lichtgewicht dashboard om de prestaties van mijn lokale Ollama-instantie te monitoren. Het doel is snel inzicht in resourcegebruik en throughput.
</context>

<task>
Bouw een webdashboard dat realtime data ophaalt van de Ollama API en toont.
</task>

<constraints>
- Toon alleen: tokens per seconde (throughput) en VRAM-gebruik (in MB of GB).
- Geen login, geen wachtwoord, geen authenticatie.
- Geen modelstatus, geen lijst van recente prompts.
- Gebruik een simpele stack (bijv. Python met Streamlit of een lichte Node.js oplossing) die makkelijk lokaal te draaien is.
</constraints>

<done_when>
Het dashboard laadt in een browser, toont de gevraagde twee metrics live (of met korte refresh) en vereist geen inloggegevens.
</done_when>

<output_format>
De volledige code voor het dashboard, de benodigde dependencies, en korte instructies om het lokaal te starten.
</output_format>
```

Aannames:
- De Ollama API is lokaal draaiend op de standaard poort (meestal 11434).
- De gebruiker heeft Python en pip (of Node/npm) geïnstalleerd voor de gekozen stack.
- "Tokens per seconde" wordt afgeleid van de API respons tijden of via een specifieke endpoint als die beschikbaar is in de actuele versie van Ollama.

Instellingen: effort medium.
