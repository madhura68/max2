Perfect. Ik kan nu de prompt genereren.

```
<context>
Ik heb een TypeScript-project met ongeveer 200 tests die momenteel met Jest werken. Ik wil migreren naar Vitest voor betere performance en modernere features.
</context>

<task>
Migreer de testsetup van Jest naar Vitest in mijn codebase.
</task>

<constraints>
- Bewaar de bestaande teststructuur en testnamen waar mogelijk
- Zorg dat alle 200 tests nog steeds slagen na de migratie
- Verwijder Jest-afhankelijkheden en voeg Vitest toe als dev dependency
- Pas de package.json scripts aan (test, test:watch, test:coverage)
- Behoud de huidige test organisatie en file naming conventions
- Zorg dat mock-functies werken zoals voorheen
</constraints>

<done_when>
- Alle 200 tests slagen met 'npm test' of 'pnpm test'
- De test coverage reports werken nog
- Er geen Jest-afhankelijkheden meer in package.json staan
- De tests starten snel met 'npm run test:watch'
</done_when>

<output_format>
Voer de migratie uit in mijn repository en geef een samenvatting van de wijzigingen.
</output_format>

<check_in>
Stop en vraag om bevestiging voordat je Jest-afhankelijkheden verwijdert als er meer dan 50 tests falen.
</check_in>
```

Aannames:
- Je gebruikt npm of pnpm als package manager
- De tests zijn standaard TypeScript zonder speciale Jest-transformaties
- Je wilt de test structuur behouden, niet herschrijven

Instellingen: effort high (vanwege de schaal van 200 tests en de impact van de migratie)
