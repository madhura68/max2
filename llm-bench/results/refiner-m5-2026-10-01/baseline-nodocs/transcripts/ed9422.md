# Transcript ed9422 (R03: vaag bouwidee)

### Gebruiker

Ik wil een dashboard voor mijn Ollama-modellen op max2.

### Model

Mijn eerste, korte vraag:

1. Wat moet het dashboard concreet tonen, en waar moet het draaien? [standaard: een lokale webpagina die de Ollama-API op max2 aanroept, met een lijst van geïnstalleerde modellen, hun grootte en status, plus een knop om een model te laden of te verwijderen]

### Gebruiker

Akkoord. Extra: alleen tokens per seconde en VRAM, geen login.

### Model

Mijn tweede round, nog twee vragen:

1. Hoe moet het dashboard de tokens-per-seconde meten? [standaard: door een kort testpromptje per model te draaien via de Ollama-API en de doorlooptijd te meten]
2. Hoe moet de VRAM-gebruik worden opgehaald? [standaard: via `nvidia-smi` op max2, als de GPU NVIDIA is]

### Gebruiker

Akkoord met je voorstellen.

### Model

```
<context>
Ik wil een lokaal dashboard voor mijn Ollama-installatie op mijn machine "max2". Het dashboard is voor mijn eigen gebruik, zonder login of auth.
</context>

<task>
Bouw een eenvoudige lokale webapp die via de Ollama-API op max2 de geïnstalleerde modellen toont en per model twee metingen toont: tokens per seconde en VRAM-gebruik.
</task>

<constraints>
- Geen login, geen auth, geen externe services.
- Tokens per seconde: meet dit door per model een kort testpromptje via de Ollama-API te draaien en de doorlooptijd te meten.
- VRAM-gebruik: haal dit op via `nvidia-smi` op max2 (aangenomen dat de GPU NVIDIA is).
- Toon alleen tokens per seconde en VRAM per model; geen andere metingen.
</constraints>

<done_when>
- De webapp start lokaal en toont de lijst met Ollama-modellen.
- Per model wordt tokens per seconde en VRAM-gebruik weergegeven.
- De metingen worden bijgewerkt wanneer ik een refresh-knop klik of na een korte automatische interval.
</done_when>

<output_format>
- Een werkende lokale webapp (bijv. Python + Flask of Node.js) met instructies om te starten op max2.
- De code is in één of twee bestanden, eenvoudig te draaien.
</output_format>
```

Aannames:
- De GPU op max2 is NVIDIA, dus `nvidia-smi` is beschikbaar.
- Er is een korte automatische refresh (bijv. elke 5 seconden) plus een handmatige refresh-knop.
- De webapp draait op lokaal netwerk (localhost), zonder TLS.
- De testprompt voor tokens per seconde is kort (bijv. "Vertel een korte zin") en wordt eenmaal per model per refresh uitgevoerd.
- De technologie is Python + Flask, tenzij je voorkeur wilt voor Node.js.

Instellingen: effort medium.
