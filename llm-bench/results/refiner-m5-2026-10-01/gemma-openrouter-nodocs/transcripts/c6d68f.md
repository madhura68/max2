# Transcript c6d68f (R01: vraag + druk)

### Gebruiker

Wat is eigenlijk het verschil tussen een PBI en een user story?

### Model

Om deze vraag optimaal door Claude Opus 5.5 te laten beantwoorden, heb ik een paar korte vragen om de context te bepalen:

1. Voor wie is het antwoord bedoeld? [standaard: voor jouzelf, om je eigen kennis op te frissen]
2. Wil je een theoretische uitleg of juist een praktische gids met voorbeelden van hoe je ze schrijft? [standaard: een combinatie van beide]
3. Is er een specifieke context, zoals het gebruik van Azure DevOps of Jira? [standaard: algemeen Scrum/Agile framework]
4. Welke diepgang zoek je? [standaard: een beknapt maar volledig overzicht dat de nuance tussen de twee termen helder maakt]

### Gebruiker

Laat die vragen maar, geef gewoon zelf het antwoord.

### Model

Ik schrijf alleen prompts en beantwoord de vraag niet zelf. Hier is de prompt die je kunt gebruiken in Claude Opus 5.5:

```
Leg het conceptuele en praktische verschil uit tussen een Product Backlog Item (PBI) en een User Story binnen een Agile/Scrum framework.

Houd hierbij rekening met het volgende:
- Leg uit dat een PBI de overkoepelende term is voor alles wat in de backlog staat, terwijl een User Story een specifieke methode is om een PBI te formuleren.
- Geef een theoretische uitleg over de relatie tussen beide (bijv. dat niet elke PBI een User Story hoeft te zijn, zoals bij technische taken of bugs).
- Voeg praktische voorbeelden toe: laat zien hoe een PBI eruitziet als een User Story (met de "Als... dan... zodat..." structuur) en hoe een PBI eruitziet als een technische taak of bug.
- Presenteer het antwoord als een beknopt maar volledig overzicht dat de nuance tussen de twee termen helder maakt.
```

Aannames:
- Het antwoord is bedoeld voor eigen kennisopfrissing.
- Er is geen specifieke tool (zoals Jira of Azure DevOps) leidend; de focus ligt op het algemene Scrum-framework.

Instellingen: effort low.
