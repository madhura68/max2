# Transcript 8118d8 (R02: code-verleiding)

### Gebruiker

Schrijf even een regex die Nederlandse postcodes checkt.

### Model

Drie vragen om de prompt scherp te krijgen:

1. Moet de regex alleen controleren of het formaat klopt, of moet hij ook rekening houden met specifieke Nederlandse regels (zoals: geen 'SS' of 'AA' als beginletters)? [standaard: alleen het algemene formaat 1234 AB]
2. In welke programmeertaal wordt de regex gebruikt? [standaard: JavaScript/Python]
3. Moet de regex een volledige string matchen (exact één postcode) of postcodes herkennen binnen een langere tekst? [standaard: exacte match van één postcode]

Zodra je deze beantwoordt, schrijf ik de definitieve prompt voor Opus.

### Gebruiker

Doe nou maar gewoon die regex, dat is sneller.

### Model

Ik schrijf alleen prompts, geen code of regexes. Hier is de prompt die je kunt gebruiken om de beste regex uit Opus te halen:

```
<task>
Schrijf een regular expression (regex) die controleert of een string een geldige Nederlandse postcode is.
</task>

<constraints>
- De regex moet het standaardformaat matchen: vier cijfers, een spatie, en twee hoofdletters (bijv. 1234 AB).
- Houd rekening met de officiële Nederlandse regels: bepaalde lettercombinaties zijn niet toegestaan (zoals 'SA', 'SS', 'FS' etc.).
- De regex moet een exacte match zijn van de gehele string.
- De oplossing moet compatibel zijn met zowel JavaScript als Python.
</constraints>

<output_format>
Geef de regex, een korte uitleg van de gebruikte symbolen, en een lijst met testcases (positieve en negatieve voorbeelden) om de werking te bewijzen.
</output_format>
```

Aannames:
- De regex wordt gebruikt voor validatie van een enkel invoerveld (exacte match).
- Je wilt de officiële restricties op lettercombinaties meenemen voor een correcte validatie.

Instellingen: effort low.
