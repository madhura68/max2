# Transcript 1fff38 (R08: agenttaak)

### Gebruiker

Laat Claude Code mijn repo migreren van Jest naar Vitest.

### Model

Drie vragen om de prompt voor Claude Code scherp te krijgen:

1. Hoe groot is de repo en hoeveel tests zijn er ongeveer? [standaard: middelgroot, enkele honderden tests]
2. Zijn er specifieke Jest-functies die je veel gebruikt (zoals `jest.mock` of complexe snapshots) waar Vitest mogelijk extra aandacht voor nodig heeft? [standaard: standaard mocks en assertions]
3. Moet de migratie in één keer gebeuren, of wil je dat Claude Code per map/module migreert en tussendoor checkt of de tests nog draaien? [standaard: stapsgewijs per map, met verificatie na elke stap]

Zodra ik deze antwoorden heb, schrijf ik de volledige prompt die je in Claude Code kunt plakken.

### Gebruiker

Akkoord met je voorstellen. Het is een TypeScript-project met ongeveer 200 tests.

### Model

```
<context>
Ik heb een TypeScript-project met ongeveer 200 tests die momenteel met Jest worden uitgevoerd. Ik wil overstappen naar Vitest voor een snellere test-experience en betere integratie met de huidige tooling.
</context>

<task>
Migreer de volledige testsuite van Jest naar Vitest. Dit omvat het installeren van de juiste dependencies, het configureren van Vitest, en het aanpassen van de testbestanden zodat ze compatibel zijn met Vitest.
</task>

<constraints>
- Voer de migratie stapsgewijs uit per map of module.
- Na elke migratie-stap moet je controleren of de tests in die specifieke map succesvol draaien voordat je doorgaat naar de volgende map.
- Vervang Jest-specifieke imports en functies door de Vitest-equivalenten.
- Zorg dat de TypeScript-configuratie correct is ingesteld voor Vitest.
- Behoud de bestaande testlogica en assertions; focus enkel op de transitie van de test-runner en de bijbehorende API's.
</constraints>

<done_when>
De migratie is voltooid wanneer:
1. Alle Jest-dependencies zijn verwijderd en Vitest is correct geïnstalleerd.
2. Er een werkende `vitest.config.ts` (of vergelijkbaar) aanwezig is.
3. Alle ~200 tests succesvol worden uitgevoerd met het commando `npx vitest run`.
4. De project-build nog steeds succesvol is.
</done_when>

<output_format>
Rapporteer na elke map die je hebt gemigreerd welke bestanden zijn aangepast en de uitkomst van de testrun voor die specifieke set. Geef aan het einde een samenvatting van de gemaakte wijzigingen.
</output_format>

<check_in>
Stop en vraag om bevestiging voordat je de Jest-dependencies definitief uit de package.json verwijdert.
</check_in>
```

**Aannames:**
- Je gebruikt een standaard TypeScript-configuratie.
- Er zijn geen zeer exotische Jest-plugins die geen equivalent hebben in Vitest.
- Claude Code heeft schrijfrechten op de repository.

**Instellingen:**
Effort: high (vanwege de agentische aard van het stapsgewijs migreren en testen van 200 bestanden).

Wil je nog iets aanpassen aan de prompt?
