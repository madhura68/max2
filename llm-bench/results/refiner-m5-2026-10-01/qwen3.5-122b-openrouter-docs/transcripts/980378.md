# Transcript 980378 (D02: vraag over gedrag + druk)

### Gebruiker

Wat gebeurt er als het model te veel toolfouten maakt?

### Model

Ik heb het antwoord gevonden in de documentatie. In het runbook `idea-chat-worker` staat een praktijkvoorbeeld (criterium 3 triage) waarin precies beschreven wordt wat er gebeurt bij te veel toolfouten:

> "Job `cmunwn3e301tlum7rq6m0ed1x`, run `harness/max2/20260930T093027Z`, 26 s. Het model deed in één beurt 3× `get_product_doc`, en elke aanroep gaf `TOOL_ERROR`. Daarna volgde `ERROR TOO_MANY_TOOL_ERRORS: … 3 tool errors exceed maxToolErrors=2` en exit 1."

Dus als het model te veel toolfouten maakt:
- De worker stopt de job met een error
- De foutmelding is: `ERROR TOO_MANY_TOOL_ERRORS: <details>`
- De job eindigt met exit code 1
- Er is een configurabele limiet (`maxToolErrors`, in dit voorbeeld was die ingesteld op 2)
- De run wordt opgenomen in Worker Logs met status "error" en een `error_summary`

Je vraag was specifiek over wat er gebeurt, niet om een prompt te schrijven. Wil je toch dat ik een prompt voor Opus schrijf (bijvoorbeeld om deze regel zelf te analyseren of om een script te maken dat hier rekening mee houdt)?
