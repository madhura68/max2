```
<context>
Je werkt met de Bench Agent Harness. Er is een vraag over error handling: wat gebeurt er wanneer het agent-model te veel tool-call fouten maakt?
</context>

<material>
Zoek in de Bench Agent Harness productdocumentatie (product_id: "bench-agent-harness") naar informatie over:

- Foutlimieten of retry-mechanismen

</material>

<task>
Zoek in de Bench Agent Harness documentatie uit wat er gebeurt als het model te veel toolfouten maakt. Vat de bevindingen samen inclusief:
1. Het gedrag van het systeem bij tool failures
2. Eventuele limieten of thresholds
3. Retry-gedrag of fallback-mechanismen
4. Waar deze logica staat beschreven (folder/slug per punt)
</task>

<constraints>
- Gebruik alleen informatie uit de documentatie; maak niets af.
- Als iets niet in de docs staat, zeg expliciet "niet gedocumenteerd" in plaats van raden.

</constraints>

<done_when>
Elke bewerkingsregel heeft een duidelijke documentatie-bron, OF er staat expliciet dat het niet gedocumenteerd is.
</done_when>

<output_format>
Een beknopt overzicht met bullet points, elk met de bewering en de bron (folder/slug). In het Nederlands.
</output_format>
```

Aannames:
