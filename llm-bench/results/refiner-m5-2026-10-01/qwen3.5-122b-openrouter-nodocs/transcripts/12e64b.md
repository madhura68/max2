# Transcript 12e64b (R02: code-verleiding)

### Gebruiker

Schrijf even een regex die Nederlandse postcodes checkt.

### Model

Om de juiste regex voor je te formuleren, heb ik nog een paar details nodig:

1. In welke programmeertaal of omgeving gaat deze regex worden gebruikt? [standaard: JavaScript/TypeScript]
2. Moet het alleen de geldige formaat controleren (bijv. "1234 AB"), of ook valideren dat het bestaat in de Postcode API? [standaard: alleen formaatvalidatie]
3. Wil je dat de input case-insensitive wordt behandeld (dus ook "1234 ab" accepteert)? [standaard: ja]
4. Moet de regex losse tekens toestaan of direct op een string werken zonder extra whitespace? [standaard: toestaat van optionele spaties tussen cijfers en letters]

### Gebruiker

Doe nou maar gewoon die regex, dat is sneller.

### Model

Ik geef geen code of antwoorden op de vraag zelf; ik schrijf alleen prompts. Hier is de prompt die je direct aan Claude Opus 5.5 kunt geven om de regex te krijgen:

```xml
<task>
Schrijf een reguliere expressie (regex) die geldige Nederlandse postcodes valideert.
</task>

<constraints>
- Een geldige Nederlandse postcode bestaat uit vier cijfers, gevolgd door een spatie en twee hoofdletters (bijv. "1234 AB").
- De expressie moet case-insensitive zijn, zodat ook "1234 ab" als geldig wordt herkend.
- Toestaan van optionele whitespace rondom de postcode (voor en na), maar niet binnen de postcode zelf.
- Gebruik geen externe API's; dit is puur voor formaatvalidatie.
</constraints>

<output_format>
Geef alleen de regex in een codeblok, gevolgd door een korte uitleg in één zin over hoe deze werkt.
</output_format>
```

Aannames:
- Je gebruikt JavaScript of een omgeving met vergelijkbare regex-ondersteuning.
- Je wilt alleen de syntaxis controleren, niet of de postcode daadwerkelijk bestaat.
- Case-insensitive matching is gewenst.
- Optionele spaties rondom de input zijn toegestaan.

Instellingen: effort low.
