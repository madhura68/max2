# Transcript e60e54 (R03: vaag bouwidee)

### Gebruiker

Ik wil een dashboard voor mijn Ollama-modellen op max2.

### Model

Drie vragen om de prompt scherp te krijgen:

1. Wat moet het dashboard precies tonen? [standaard: een lijst van geïnstalleerde modellen met naam, grootte en laatste gebruik, plus een knop om een model te laden/verwijderen]
2. Wat voor omgeving is "max2"? [standaard: een Mac (Apple Silicon) waarop Ollama via de officiële app draait, macOS]
3. Welke technologie en vorm? [standaard: een lokale webapp: Python FastAPI backend die de Ollama REST API (localhost:11434) aanspreekt, met een eenvoudige HTML/JS frontend, te starten met één commando]

### Gebruiker

Akkoord. Extra: alleen tokens per seconde en VRAM, geen login.

### Model

```
<context>
Ik draai Ollama op mijn Mac (Apple Silicon, macOS) via de officiële app. Ik wil een lokaal dashboard in de browser om mijn Ollama-modellen te overzien en te beheren. Het dashboard is puur voor eigen gebruik; een login is niet nodig.
</context>

<task>
Bouw een lokale webapp bestaande uit een Python FastAPI backend en een eenvoudige HTML/JS frontend. De backend spreekt de Ollama REST API op localhost:11434 aan. De app toont een overzicht van de geïnstalleerde modellen en de systeemstatus, en biedt basisacties per model.
</task>

<constraints>
- Geen login of authenticatie van enige soort; de app luistert alleen op localhost.
- Het dashboard toont per model: naam, grootte, en de laatste keer dat het is gebruikt.
- De systeemstatus toont uitsluitend: tokens per seconde en VRAM-gebruik. Geen andere prestatie- of systeemmetrieken (geen CPU, RAM of temperatuur).
- VRAM-gebruik wordt op macOS niet door Ollama gerapporteerd; bepaal de waarde op een gangbare macOS-manier (bijvoorbeeld via de processen van Ollama) en vermeld in de code welke methode wordt gebruikt.
- Per model zijn de volgende acties mogelijk: laden (warm-up) en verwijderen.
- Gebruik geen externe databases; alle data komt live uit de Ollama API en het systeem.
</constraints>

<done_when>
Met één commando start de app en opent de browser de dashboardpagina. De lijst van modellen komt uit de Ollama API, de acties laden en verwijderen werken, en de systeemstatus toont tokens per seconde en VRAM.
</done_when>

<output_format>
De volledige broncode (backend en frontend), de installatiestappen voor de benodigde Python-pakketten, en het commando om de app te starten.
</output_format>
```

Aannames:
- "max2" is een Mac (Apple Silicon) met macOS, waarop Ollama via de officiële app draait.
- Python 3 is geïnstalleerd; de app luistert op localhost, dus een login is overbodig.
- Tokens per seconde wordt afgeleid uit de Ollama API (eval-count en eval-duration bij een generatie); het dashboard toont de laatste bekende waarde.
- De frontend is één eenvoudige HTML/JS-pagina zonder buildstap.

Instellingen: effort medium.
Wil je nog iets aanpassen?
