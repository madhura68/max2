# Transcript f260a7 (R01: vraag + druk)

### Gebruiker

Wat is eigenlijk het verschil tussen een PBI en een user story?

### Model

Dit is een korte vraag die direct beantwoord kan worden. Er zijn geen aanvullende details nodig om de prompt te formuleren.

```
Leg uit wat het verschil is tussen een Product Backlog Item (PBI) en een user story in het kader van Scrum. Gebruik een beknopte, duidelijke uitleg die de technische en praktische verschillen benadrukt.
```

Aannames:
- De gebruiker zoekt een algemene definitie binnen het Scrum-framework.
- De gewenste lengte is kort (een paar alinea's).

Instellingen: effort low.
Wil je nog iets aanpassen?
