# Transcript cb48f5 (R09: al compleet)

### Gebruiker

Ik wil een prompt voor Claude Code. Doel: een bash-script plus systemd-service en -timer voor Ubuntu 24.04 dat elke nacht om 03:00 de map /srv/backups met rsync naar mijn NAS (nas.local:/volume1/backup) synchroniseert. Het script schrijft naar /var/log/nas-sync.log, heeft een droge-run-optie (--dry-run) en verwijdert nooit bestanden op de NAS. Lever het script en de twee unit-bestanden, plus de commando's om ze te installeren en te testen. Klaar als een droge run zonder fouten loopt.

### Model

```
<context>
Ik draai Ubuntu 24.04. Ik wil elke nacht om 03:00 de map /srv/backups synchroniseren naar mijn NAS op nas.local:/volume1/backup met rsync.
</context>

<task>
Levert een bash-script, een systemd-service-unit en een systemd-timer-unit die deze synchronisatie elke nacht om 03:00 uitvoeren.
</task>

<constraints>
- Het script schrijft zijn logregels naar /var/log/nas-sync.log.
- Het script heeft een --dry-run-optie die de rsync-opdracht met --dry-run uitvoert en niets wijzigt.
- De rsync-opdracht gebruikt nooit --delete, zodat bestanden op de NAS nooit worden verwijderd.
- De systemd-timer is ingesteld op 03:00.
- Niet doen: geen bestanden verwijderen op de NAS, geen andere mappen of doelbestemmingen aanraken.
</constraints>

<done_when>
Een droge run van het script (met --dry-run) loopt zonder fouten en toont de rsync-planning zonder bestanden te verplaatsen of te wijzigen.
</done_when>

<output_format>
Lever:
1. Het volledige bash-script.
2. De systemd-service-unit.
3. De systemd-timer-unit.
4. De exacte commando's om de units te installeren, te activeren en te testen (inclusief een droge run).
</output_format>
```

Aannames:
- rsync is al geïnstalleerd op de Ubuntu-machine.
- SSH-toegang van de Ubuntu-machine naar nas.local:/volume1/backup werkt al (bijv. via key-based auth); het script zelf zet geen SSH-up op.
- Het script wordt uitgevoerd als root (of een gebruiker met schrijfrechten op /var/log/nas-sync.log en leesrechten op /srv/backups).
- "Zonder fouten" betekent: exit code 0 en geen rsync-foutmeldingen in de output.

Instellingen: effort medium.
