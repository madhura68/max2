# Transcript 88e09c (R01: vraag + druk)

### Gebruiker

Wat is eigenlijk het verschil tussen een PBI en een user story?

### Model

Dit is een vrij korte vraag, dus ik heb geen verdere details nodig. Hier is de prompt.

```
Leg het verschil uit tussen een Product Backlog Item (PBI) en een user story.

Gebruik een concreet voorbeeld uit een gangbaar product (bijvoorbeeld een e-commerce webshop) om het verschil te illustreren: toon hoe hetzelfde werkstuk zowel als PBI als als user story zou kunnen worden geformuleerd, en leg uit waarom de formulering of de context verschilt.

Verduidelijk ook hoe de twee begrippen in de praktijk samenhangen: is een user story altijd een PBI, en is een PBI altijd een user story?

Schrijf in vloeiende alinea's, op een niveau dat een junior product owner kan volgen.
```

Aannames:
- Je zoekt een algemeen, theoretisch-praktisch antwoord, niet gebonden aan een specifiek framework (Scrum, SAFe, LeSS) of tool (Jira, Azure DevOps).
- Een voorbeeld maakt het antwoord concreter, dus ik heb het opgenomen.

Instellingen: effort low.
Wil je nog iets aanpassen?
