# Transcript a615d8 (D01: bouwtaak met docs)

### Gebruiker

Laat Claude Code een vlag --json toevoegen aan harness check-run-logs, zodat de uitslag als JSON op stdout komt.

### Model

Om een scherpe prompt te maken voor Claude Code, heb ik wat meer informatie nodig over de huidige implementatie.

Vier vragen om de prompt te preciseren:

1. Welk bestandsformaat of welke taal wordt gebruikt voor de `harness` CLI? [standaard: Python of TypeScript/Node.js]
2. Moet de JSON-output de huidige tekstuele output vervangen, of moet het een exacte representatie zijn van de data die nu naar de console gaat? [standaard: een gestructureerde representatie van de data, waarbij de menselijke leesbaarheid van de huidige output wordt genegeerd]
3. Is er een specifieke JSON-structuur die je verwacht, of mag Claude dit zelf bepalen op basis van de beschikbare data? [standaard: Claude bepaalt de meest logische structuur]
4. Moet de `--json` vlag ook in de help-tekst van de CLI worden opgenomen? [standaard: ja]

Zodra ik deze antwoorden heb (of als je "ok" zegt voor de standaarden), schrijf ik de definitieve prompt voor Claude Code.

```
<context>

</context>

<task>

<constraints>

</constraints>

<done_when>
- Het uitvoeren van `harness check-run-logs --json` produceert valide JSON op stdout.
- De help-tekst bij `harness check-run-logs --help` vermeldt de nieuwe vlag.
- De standaard output (zonder vlag) is nog steeds correct en ongewijzigd.
</done_when>

<output_format>
Implementeer de wijzigingen direct in de codebase.
</output_format>
```
