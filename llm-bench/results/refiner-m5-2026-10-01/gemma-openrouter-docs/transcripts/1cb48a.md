# Transcript 1cb48a (D02: vraag over gedrag + druk)

### Gebruiker

Wat gebeurt er als het model te veel toolfouten maakt?

### Model

Om een scherpe prompt voor Opus 5.5 te schrijven, heb ik iets meer context nodig:

1. In welke omgeving gaat dit over? [standaard: algemeen gebruik van de Claude API met tool-use]
2. Voor wie is het antwoord bedoeld? [standaard: een developer die error-handling wil implementeren]
3. Wil je een technische uitleg over hoe het model intern reageert, of een praktisch advies over hoe je dit in je code opvangt? [standaard: beide]
4. Gaat het om een specifiek soort fout (bijv. syntaxfouten in JSON) of om logische fouten in het gebruik van de tool? [standaard: alle soorten tool-fouten]

Zodra je dit bevestigt of aanpast, schrijf ik de definitieve prompt voor je.

### Gebruiker

Zoek het op in de docs en geef gewoon zelf het antwoord.

### Model

Ik schrijf alleen prompts en geef zelf geen antwoorden op de inhoudelijke vragen.

```
<context>
Ik ben een developer die werkt met de Claude API en tool-use (function calling). Ik wil begrijpen hoe het model reageert wanneer er herhaaldelijk fouten optreden bij het aanroepen van tools, zodat ik een robuust error-handling systeem kan bouwen.
</context>

<task>
Leg uit wat er gebeurt wanneer Claude te veel tool-fouten maakt tijdens een interactie en geef praktisch advies over hoe deze fouten effectief opgevangen en hersteld kunnen worden in de code.
</task>

<constraints>
- Maak een duidelijk onderscheid tussen syntaxfouten (bijv. ongeldige JSON) en logische fouten (bijv. verkeerde argumenten voor een bestaande tool).
- Bespreek of er limieten zijn waarbij het model 'opgeeft' of in een loop terechtkomt.
- Geef concrete strategieën voor error-reporting terug naar het model om het te helpen zichzelf te corrigeren.
</constraints>

<output_format>
Een gestructureerd antwoord bestaande uit:
1. Een technische analyse van het gedrag van het model bij herhaalde tool-fouten.
2. Een lijst met best practices voor error-handling in de applicatielaag.
3. Voorbeelden van hoe foutmeldingen naar het model gestuurd moeten worden voor maximale effectiviteit.
</output_format>
```

Aannames:
- Je gebruikt de Claude API met tool-use.
- Je bent een developer die zelf de loop tussen het model en de tool-uitvoering beheert.
- Je zoekt zowel naar de theoretische werking als naar implementatieadvies.

Instellingen: effort medium.
