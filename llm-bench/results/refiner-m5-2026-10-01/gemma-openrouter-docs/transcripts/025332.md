# Transcript 025332 (D01: bouwtaak met docs)

### Gebruiker

Laat Claude Code een vlag --json toevoegen aan harness check-run-logs, zodat de uitslag als JSON op stdout komt.

### Model

Vier vragen om de prompt scherp te krijgen:

1. Is er een specifiek JSON-schema waaraan de output moet voldoen, of is de huidige structuur van de logs simpelweg omgezet naar JSON voldoende? [standaard: de huidige informatie in de logs, maar dan in JSON-formaat]
2. Moet de normale tekst-output volledig worden vervangen door JSON wanneer de vlag wordt gebruikt, of komt de JSON als aanvulling? [standaard: volledig vervangen op stdout]
3. Zijn er bestaande voorbeelden van `--json` vlaggen in andere delen van de harness die als referentie gebruikt moeten worden? [standaard: Claude Code moet zelf zoeken naar bestaande patronen in de codebase]
4. Moet de vlag ook in de help-tekst/documentatie van het commando worden opgenomen? [standaard: ja]

Zodra je deze beantwoordt (of "ok" zegt voor de standaarden), schrijf ik de definitieve prompt voor Claude Code.

### Gebruiker

Akkoord met je voorstellen.

### Model

```
<context>
Ik wil dat de uitslag van het commando `harness check-run-logs` machine-leesbaar wordt gemaakt door een JSON-output optie toe te voegen.
</context>

<task>
Voeg een vlag `--json` toe aan het commando `harness check-run-logs` zodat de uitslag als JSON op stdout wordt geschreven.
</task>

<constraints>
- Wanneer de vlag `--json` wordt gebruikt, moet de normale tekst-output volledig worden vervangen door JSON op stdout.
- De JSON-structuur moet de huidige informatie uit de logs representeren.
- Zoek in de codebase naar bestaande implementaties van `--json` vlaggen om consistentie in patronen en stijl te waarborgen.
- Update de help-tekst en documentatie van het commando om de nieuwe vlag te beschrijven.
- Behoud de huidige tekst-output wanneer de vlag niet wordt gebruikt.
</constraints>

<done_when>
- Het commando `harness check-run-logs --json` produceert valide JSON die alle relevante log-informatie bevat.
- Het commando `harness check-run-logs` (zonder vlag) produceert nog steeds de oorspronkelijke tekst-output.
- De help-tekst van het commando vermeldt de `--json` optie.
</done_when>

<output_format>
Voer de wijzigingen door in de code en geef een korte samenvatting van de aangepaste bestanden en de gekozen JSON-structuur.
</output_format>
```

Aannames:
- Claude Code heeft toegang tot de volledige codebase van de harness.
- Er is een bestaand patroon voor CLI-argumenten in de codebase dat gevolgd kan worden.
- De huidige output van `check-run-logs` is gestructureerd genoeg om naar JSON te vertalen.
