# Transcript 61cef7 (D04: feit niet in de docs)

### Gebruiker

Laat de harness bij een mislukte job een melding naar ons Slack-kanaal sturen.

### Model

Vier vragen om de prompt scherp te krijgen:

1. Wordt deze prompt gebruikt in een chat-app (waarbij je de code plakt) of in Claude Code (die direct toegang heeft tot je bestanden)? [standaard: Claude Code]
2. Hoe moet de melding verstuurd worden? [standaard: via een Slack Incoming Webhook]
3. Welke informatie moet in de melding staan? [standaard: Job ID, foutmelding en een link naar de logs]
4. Waar moet de Slack-configuratie (zoals de Webhook URL) worden opgeslagen? [standaard: als omgevingsvariabele (env var)]

Zodra ik dit weet, schrijf ik de volledige prompt voor Opus.

### Gebruiker

Akkoord met je voorstellen.

### Model

```
<context>
Ik wil de `bench-agent-harness` uitbreiden zodat het team direct op de hoogte is wanneer een job mislukt. De meldingen moeten naar een specifiek Slack-kanaal worden gestuurd.
</context>

<task>
Implementeer een functionaliteit in de harness die een melding naar Slack stuurt bij een mislukte job.
</task>

<constraints>
- Gebruik een Slack Incoming Webhook voor het versturen van de berichten.
- De Webhook URL mag niet hardcoded zijn, maar moet worden ingelezen vanuit een omgevingsvariabele (env var).
- De Slack-melding moet de volgende informatie bevatten:
    - De Job ID.
    - De foutmelding (error message).
    - Een directe link naar de logs van de betreffende job.
- Zorg dat de implementatie robuust is: een fout in het versturen van de Slack-melding mag de harness zelf niet laten crashen.
</constraints>

<done_when>
De implementatie is voltooid wanneer een geforceerde mislukte job resulteert in een correct geformatteerde Slack-melding met de Job ID, de foutmelding en de link naar de logs in het gekoppelde kanaal.
</done_when>

<output_format>
Pas de nodige bestanden in de codebase aan en geef een korte uitleg over welke wijzigingen zijn doorgevoerd en welke omgevingsvariabele er geconfigureerd moet worden.
</output_format>
```

**Aannames:**
- De harness heeft al een mechanisme om te detecteren wanneer een job mislukt.
- Er is een manier om een URL naar de logs te genereren op basis van de Job ID.

**Instellingen:**
- Effort: medium.
- Tooling: Gebruik Claude Code om de relevante bestanden voor job-lifecycle en error-handling te vinden en aan te passen.
