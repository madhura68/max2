# Transcript 271661 (D01: bouwtaak met docs)

### Gebruiker

Laat Claude Code een vlag --json toevoegen aan harness check-run-logs, zodat de uitslag als JSON op stdout komt.

### Model

Ik ga een prompt maken waarmee Claude Code deze vlag kan implementeren. Om dit precies te doen, heb ik nog een paar vragen:

1. Welke JSON-structuur moet de output hebben? [standaard: een lijst met objecten die de huidige velden van de log-output bevatten]
2. Moet de normale tekst-output volledig worden onderdrukt wanneer `--json` wordt gebruikt? [standaard: ja, alleen JSON op stdout]
3. Moeten er specifieke tests worden toegevoegd of bestaande tests worden bijgewerkt om deze vlag te valideren? [standaard: ja, voeg een nieuwe test toe die de JSON-output valideert]
4. Is er een specifieke library voor JSON-handling die in dit project wordt gebruikt? [standaard: de standaard library van de taal waarin het geschreven is]

Zodra ik deze antwoorden heb (of als je akkoord gaat met de standaarden), schrijf ik de volledige prompt voor Claude Code.

### Gebruiker

Akkoord met je voorstellen.

### Model

```
<context>
De opdracht 'harness check-run-logs' moet worden uitgebreid zodat de resultaten machine-leesbaar zijn. Dit is nodig om de output van deze check te kunnen gebruiken in andere automatiseringstools.
</context>

<task>
Voeg een `--json` vlag toe aan de opdracht 'harness check-run-logs' die ervoor zorgt dat de uitslag als een JSON-array van objecten op stdout wordt geprint.
</task>

<constraints>
- Wanneer de vlag `--json` wordt gebruikt, moet de normale menselijke tekst-output volledig worden onderdrukt.
- De JSON-structuur moet een lijst met objecten zijn die alle relevante velden bevatten die nu ook in de tekst-output worden getoond.
- Gebruik de standaard JSON-library van de taal waarin het project is geschreven.
- De bestaande functionaliteit zonder de `--json` vlag mag niet veranderen.
</constraints>

<done_when>
- De opdracht 'harness check-run-logs --json' produceert valide JSON op stdout.
- Er is een nieuwe test toegevoegd die specifiek controleert of de `--json` vlag de correcte JSON-structuur oplevert en geen extra tekst print.
- De opdracht zonder de vlag werkt nog steeds zoals voorheen.
</done_when>

<output_format>
Pas de relevante bronbestanden aan en voeg het nieuwe testbestand toe. Geef een kort overzicht van de gewijzigde bestanden.
</output_format>
```

- Er is een bestaande testsuite in het project waar een nieuwe test aan toegevoegd kan worden.
