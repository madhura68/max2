# Transcript 2508b0 (D03: analyse van run-logs)

### Gebruiker

Ik wil de run-logs van vannacht laten nalopen op mislukte jobs.

### Model

Om een scherpe prompt voor Opus te maken, heb ik iets meer informatie nodig over de omgeving en de logs.

Vier vragen om de prompt te verfijnen:

1. Waar staan de logs en hoe krijgt Opus er toegang toe? [standaard: Claude Code heeft toegang tot de bestanden in de huidige directory]
2. Waar moet Opus op letten om een 'mislukte job' te herkennen? [standaard: zoek naar keywords als "ERROR", "FAILED" of "Exception"]
3. Wil je alleen een lijst met fouten, of moet Opus ook direct een analyse/oplossing per fout voorstellen? [standaard: een lijst met de foutmelding, de betreffende job en een korte analyse van de oorzaak]
4. Welke tijdsperiode precies? [standaard: alles vanaf 00:00 uur vannacht tot nu]

Zodra je deze beantwoordt (of "ok" zegt bij de standaarden), schrijf ik de volledige prompt voor je.

### Gebruiker

Akkoord met je voorstellen. Het gaat om de harness-worker op max2.

### Model

Hier is de complete prompt voor Opus (of Claude Code). Ik heb de technische details over de mappenstructuur en de foutindicatoren uit de documentatie toegevoegd om de nauwkeurigheid te vergroten.

```markdown
<context>
Ik wil de run-logs van de harness-worker op de max2-server nalopen om te zien welke jobs vannacht zijn mislukt. 
</context>

<task>
Doorzoek de directory `/srv/scrum4me/worker-logs/harness/max2/runs/` naar logbestanden die sinds 00:00 UTC vandaag zijn aangemaakt. Identificeer alle mislukte jobs en maak hiervan een overzicht.
</task>

<constraints>
- Een job wordt als mislukt beschouwd als het logbestand een meta-regel bevat die begint met `ERROR` of als het bestand eindigt met `exit code=1`.
- Noteer per mislukte job:
    1. De Job ID (te vinden in de regel `claimed job_id=...`).
    2. De specifieke foutmelding (uit de `ERROR`-regel).
    3. Een korte analyse van de oorzaak op basis van de voorafgaande regels in het logbestand.
- Negeer succesvolle jobs.
- Als er geen fouten zijn gevonden, meld dan simpelweg dat alle jobs sinds middernacht succesvol waren.
- Lever wat er gevraagd is binnen de beoogde scope. Als een betere aanpak voor het vinden van deze fouten bestaat, noem dit dan kort in één zin en voer daarna de taak uit zoals gevraagd.
</constraints>

<done_when>
Er is een lijst gepresenteerd van alle mislukte jobs sinds middernacht, inclusief de job ID, de foutmelding en de analyse.
</done_when>

<output_format>
Een heldere lijst of tabel met de kolommen: Job ID | Foutmelding | Analyse.
</output_format>
```

**Aannames:**
- De logs staan op de server waar Claude Code toegang toe heeft via het pad `/srv/scrum4me/worker-logs/harness/max2/runs/`.
- De tijdzone van de bestandsnamen is UTC.
- De definitie van 'mislukt' beperkt zich tot de `ERROR`-meta-regels en de `exit code=1`.

**Instellingen:**
- **Effort:** Medium.
- **Bijlagen:** Geen (Opus moet zelf de bestanden op de schijf lezen).
