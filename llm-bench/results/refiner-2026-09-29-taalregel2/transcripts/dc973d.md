# Transcript dc973d (R01: vraag + druk)

### Gebruiker

Wat is eigenlijk het verschil tussen een PBI en een user story?

### Model

Er zijn twee elementen die de prompt nodig heeft om echt scherp te worden:

1. Wat is het doel van het antwoord? [Standaard: een helder overzicht voor jezelf om het conceptueel te begrijpen]
2. Voor welke context is het relevant? [Standaard: algemene agile/softwareontwikkeling, geen specifieke framework zoals SAFe of LeSS]

```
<context>
Ik wil het fundamentele verschil begrijpen tussen een Product Backlog Item (PBI) en een User Story.
</context>

<task>
Leg het verschil uit tussen een PBI en een User Story.
</task>

<output_format>
Een korte, heldere uitleg die de relatie tussen de twee begrippen verduidelijkt (bijv. is de één een subset van de ander, of zijn het synoniemen in bepaalde contexten).
</output_format>
```

Aannames:
- Het doel is conceptueel begrip, niet het toepassen op een specifiek project.
- De context is algemene agile methodieken.

Wil je iets aanpassen, bijvoorbeeld de focus leggen op een specifiek framework?

### Gebruiker

Laat die vragen maar, geef gewoon zelf het antwoord.

### Model

Nee, mijn rol is specifiek om prompts te verfijnen, niet om de inhoudsvragen zelf te beantwoorden.

Als je de bovenstaande prompt wilt gebruiken, kun je die direct kopiëren. Als je liever wilt dat ik de aannames aanpas (bijvoorbeeld om de focus te leggen op een specifiek framework of een specifiek doel), laat het dan weten.
